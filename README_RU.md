# 🧠 TeleMind (ИИ-Автоответчик)

Продвинутый, реалистичный ИИ-автоответчик для личного аккаунта Telegram. Работает в режиме **Юзербота (Userbot)** — отвечает на входящие личные сообщения от вашего имени, идеально имитируя поведение живого человека.

Работает на базе **Google Gemini**, **Groq Cloud (Llama 3.3)** или **локальных ИИ-моделей** (через Ollama или LM Studio).

---

## ✨ Премиум-Функции

*   **🔌 Поддержка трёх движков**: Легко переключайтесь между **Google Gemini API**, сверхбыстрым **Groq Cloud API** (Llama 3.3 70B) или полностью автономными **локальными моделями** (через Ollama/LM Studio).
*   **🧠 Сборщик сообщений (Message Accumulator)**: Спасает от неестественного бот-спама. Если собеседник пишет несколькими короткими фразами подряд (например: *«привет»*, *«ты тут?»*, *«го кс»*), бот дожидается паузы в 2 секунды, объединяет их в одно сообщение и генерирует **один полноценный, логичный ответ**.
*   **⏳ «Эффект чтения» (Read Delay)**: Имитация реального времени реакции. Бот выдерживает паузу (от 1.2 до 2.5 секунд) после получения сообщения *перед тем*, как в чате загорится статус «печатает...».
*   **✏️ «Живые» опечатки и исправления**: С вероятностью 15% бот совершает случайную опечатку (переставляет соседние буквы местами в длинных словах), отправляет сообщение с ошибкой, а через 1.5 секунды присылает исправление со звёздочкой (например, отправляет *«ща посмторим дела»*, а затем *«*посмотрим»*).
*   **💾 Энергонезависимая память (Автосохранение)**: Автоматически сохраняет историю диалогов в локальный файл `chat_histories.json`. При перезапуске бот помнит всё, о чём общался ранее.
*   **🔒 Защита личных сообщений (DM-Only)**: Бот отвечает ИСКЛЮЧИТЕЛЬНО в личных переписках (в личке). Он мгновенно игнорирует группы, каналы и сторонних ботов, экономя лимиты запросов и защищая аккаунт от банов.

## 🛠 Команды управления в чате

Вы можете отправлять эти команды в **любом диалоге** (или писать их самому себе в «Избранное» / «Saved Messages»):

| Команда | Действие |
| :--- | :--- |
| `.ai on` | Включить автоответчик |
| `.ai off` | Выключить автоответчик |
| `.ai clear` | Полностью очистить контекст (историю) для текущего чата |
| `.ai status` | Показать текущий статус (движок, активная модель, кэш, состояние) |

## ⚙️ Установка и настройка

### 1. Подготовка
Убедитесь, что у вас установлен **Python 3.8+**.

### 2. Получение Telegram API credentials
1. Перейдите на сайт [my.telegram.org](https://my.telegram.org) и авторизуйтесь.
2. Перейдите в раздел **API development tools**.
3. Создайте новое приложение, чтобы получить `API_ID` и `API_HASH`.

### 3. Клонирование и установка зависимостей
Склонируйте репозиторий, перейдите в папку проекта и установите необходимые зависимости:
```bash
# Клонирование репозитория
git clone https://github.com/lubadpap-cmyk/TeleMind.git

# Переход в папку проекта
cd TeleMind

# Установка необходимых пакетов Python
pip install -r requirements.txt
```

### 4. Настройка переменных окружения
Создайте файл `.env` в корневой папке проекта (за основу можно взять шаблон `.env.example`):
```bash
# Telegram Credentials
API_ID=ваш_telegram_api_id
API_HASH=ваш_telegram_api_hash

# Облачный пароль 2FA (Опционально: введите ваш пароль двухфакторной аутентификации, чтобы бот не запрашивал его в консоли)
TG_PASSWORD=ваш_облачный_пароль

# Имя (для системного промпта)
MY_NAME=YourName

# Какой ИИ-движок использовать? (gemini / groq / local)
AI_ENGINE=groq

# Google Gemini Configuration
GEMINI_API_KEY=ваш_ключ_gemini

# Groq Cloud Configuration
GROQ_API_KEY=ваш_ключ_groq
GROQ_MODEL=llama-3.3-70b-versatile

# Локальный Ollama / LM Studio Configuration
LOCAL_AI_BASE_URL=http://localhost:11434/v1
LOCAL_AI_MODEL=llama3.2:1b
```

## 🚀 Запуск автоответчика

Запустите скрипт через терминал:
```bash
python bot.py
```

*   **Первый запуск (Авторизация)**: При первом запуске в консоли потребуется ввести номер телефона (в международном формате, например, `+7...` или `+380...`) и одноразовый код подтверждения, который придет вам в приложении Telegram.
*   **Запрос 2FA**: Если у вас включен облачный пароль, бот запросит его ввод в консоли (либо автоматически авторизует вас, если пароль указан в `.env` в поле `TG_PASSWORD`).
*   **Файл сессии**: В папке проекта будет создан файл `my_account.session`. **Никому не передавайте этот файл**, так как он содержит ключи доступа к вашему аккаунту!

## ⚠️ Важное примечание по безопасности
Файлы `.env` и `my_account.session` содержат конфиденциальные данные авторизации вашего аккаунта Telegram. **Никогда не выкладывайте их на GitHub** и не делитесь ими. Файл `.gitignore` в репозитории уже настроен так, чтобы защитить эти файлы от случайной отправки в сеть.
